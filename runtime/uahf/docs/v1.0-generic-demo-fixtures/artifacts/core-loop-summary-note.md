# 핵심 루프 4단계 요약 노트 (시연 artifact)

이 노트는 위임 메시지(`../channels/delegation-message.md`)의 task 산출물이다. 핵심 루프(위임→구현→검증→승인, specs/00-glossary.md J-11)의 4단계를 각각 요약하고, 위임 메시지 필수 필드를 열거한다. 작성 주체는 Worker 역할이며, 상위 규약(`../conventions/agent-conventions.md`)과 역할 정의(`../roles/worker.md`)를 준수한다.

## 1. 핵심 루프 4단계 (각 1문장 이상 — done 1)

- **위임 (Delegation):** Advisor가 위임 메시지(02 §3.2-B 8필드)로 작업 대상·산출물·완료 조건을 명시해 Worker에게 넘긴다. 위임 메시지 파일이 호출 채널의 실물이 된다(BP-10).
- **구현 (Implementation):** Worker가 위임된 입력·출력·완료 조건의 범위 안에서 산출물을 생성하고, Verify 통과 뒤 완료 보고(02 §3.2-C)를 남긴다. 착수 시 역할 정의 파일을 로드해 자신의 경계를 확인한다(BP-2).
- **검증 (Verification):** Verifier가 완료 보고를 그대로 신뢰하지 않고 산출물 자체를 근거로 완료 조건 항목별 판정(충족/위반/판정 불가)을 독립적으로 낸다 — 구현 주체와 검증 주체는 분리된다(02 §3.2-A).
- **승인 (Approval):** Advisor가 검증이 통과(Pass)한 경우에만 최종 승인하며, 실패면 재작업으로 되돌린다. 승인은 승인 기록 파일에 남는다.

## 2. 위임 메시지 필수 필드 7종 열거 (done 2)

위임 메시지(02 §3.2-B)의 필수 필드는 다음 7종이다.

1. **from** — 위임하는 역할.
2. **to** — 수임하는 역할.
3. **task** — 작업 요약.
4. **input** — 명확한 입력(무엇을 대상으로 하는가).
5. **output** — 명확한 출력(기대 산출물과 위치).
6. **done** — 완료 조건(검증 가능한 형태).
7. **context** — 착수 전 읽어야 할 문서 목록.

(constraints는 선택 필드이므로 필수 7종에 포함되지 않는다 — 02 §3.2-B.)

## 3. 산출 경계 (done 3)

이 노트는 위임 output이 지정한 **단일 파일**이며, 픽스처 밖 파일을 생성·수정하지 않는다(constraints 준수).
