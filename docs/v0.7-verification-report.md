## §0. 이 문서의 위치와 판정 경계

- **이 문서는 검증 리포트(06 §3.2-A) 1건이다.** Verify 연산(06 §3.1)의 출력이며, verifier-protocol.md(V3) §2의 5단계(입력 수령 → 기준 확인 → 항목별 판정 → 최종 판정 도출 → 리포트 산출)를 그대로 밟았다. 판정 대상 산출물·물리 데이터(loop-data/·memory-data/·픽스처 포함)를 일절 수정·생성하지 않았다 (06 INV-6 — 본 검증에서 생성한 저장소 파일은 이 리포트 1개뿐이다).
- **자기 적용 (위임 명시).** 스키마 = verification-report.md(V1) §2/§3/§4 (6필드 절 구조 §1~§6, 항목별 판정 5필드 표, 결정적 도출), 유형 = criteria-catalog.md VT-1~VT-5·기준 부류 4종(각 항목 VT 열 결합 표기), rework 포맷 = rework-instruction.md(V4). 정본은 06 §3.2가 유지한다. 문서 구조는 docs/v0.6-verification-report.md 관례 동형이다.
- **독립성 (V1/INV-1).** 모든 판정은 산출물 자체와 파일 시스템 실측·독립 재계산(직접 파싱·재도출·전수 스캔·mtime/크기 실측·행 재계수)을 근거로 했다. 전 Task(WF1~WF9, WF8/WF13/WF14/WF15 격리 개정 포함) 완료 보고의 self_check 충족 주장, 각 문서의 "자가 전수 스캔 0건" 기록, 시연 수행 기록(docs/v0.7-demo.md)의 "전건 일치"·"기존 39건 무변경" 주장, 시연 CP2 리포트 3건의 판정 기재는 전부 검사 대상(claim)으로만 취급했고 판정 근거로 삼지 않았다. loop-data 파싱·회수 집합 재계산·final_verdict 재도출·교집합 재계산·경계 실측은 전부 Verifier가 직접 재수행했다.
- **최종 승인 아님.** 본 리포트는 CP2 독립 판정이다. 최종 승인·재량 판정(CP3)은 Advisor 소관이며, 본 리포트는 조건부·재량 항목을 스스로 통과 처리하지 않는다 (06 §3.2-C).
- **판정의 결정성 (06 INV-5).** 최종 판정은 §3 항목별 판정 집합에서 06 §3.2-C 규칙으로 결정적으로 도출했다(§4). 위반의 경중을 재량으로 감면하지 않았다.
- **잔존 서술 판정 규칙 (V4 §4 적용).** "잔존 0건"·"무변경" 류 전칭 판정은 라이브 본문에 적용했고, 이력 행(§9)·이전 결함의 인용·교정 경위·시점 명시 실측 스냅샷은 계상하지 않았다 (rework-instruction.md §4 — 예: ⑨ loop-binding의 "L8 draft 미생성 → 실재" 경위 서술, ⑥ workflow-binding §7의 WF6 시점 "v0.7 시연 문서 미생성" 실측 스냅샷).
- **Advisor 결정의 판정 기준.** 판정 대상에 반영된 Advisor 결정(DP-W1~W6·OQ-WB-1 해소·파일 분할·충돌 시연 설계·OQ-9 동형 채택)은 각 산출물의 결정 기록 절·demo-procedure §10.2·demo.md §0.2에 명문화되어 있다. 본 판정의 기준은 그 결정의 재평가가 아니라, **결정 기록의 실재와 07 정본과의 정합(계약 재정의 여부)**이다 (위임 명시).
