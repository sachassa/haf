> **시연 픽스처 — 실계약 문서 아님.** 이 파일은 v0.6 Loop Engine 시연(Task L10, 시연 ⓒ 한도 초과 에스컬레이션)을 위해 구성된 **자기완결 대상 명세**다. specs/·framework/ 등 실계약 문서가 **아니다**. 이 파일과 그 산출물(output-c.md)은 `docs/v0.6-demo-fixtures/` **내부에만** 존재한다 (v0.6-demo-procedure §4.2 격리, CP2 전수 스캔 제외 verifier_scope).
>
> **의도적 결함 정당 보유 (시연 ⓒ용 — done 상호 모순, 원리적 동시 충족 불가).** §B done ②(표의 데이터 행 수 = 정확히 3)와 ③(표의 데이터 행 수 = 정확히 4)은 **상호 모순**된다 — 하나의 표의 데이터 행 수가 3이면서 동시에 4일 수 없으므로 **어떤 산출로도 ②·③ 동시 충족이 원리적으로 불가**하다. 따라서 각 재작업 시도가 서로 다른 산출을 내도 CP2가 미충족 조건을 반복 검출 → 반복 Fail → retry.limit(2, config-schema §7) 초과 → 에스컬레이션(03 §8 예3). 이 모순은 한도 초과 에스컬레이션 실증을 위한 **의도적·정당 보유**이며 실계약 결함이 아니다.
