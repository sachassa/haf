# out-t3 — 색인 사용 안내 (consumes 계약 Y)

## 1. 소비한 확정 계약 (계약 Y 문면 인용)

아래는 fixture-t3-spec "계약 문면" 절에서 확정 제공된 계약 Y 문면을 그대로 인용한 것이다.

> out-t2.md는 2열 표로 용어 3개를 가나다 순(감마 → 베타 → 알파)으로 나열한다.

## 2. 사용 안내

색인은 가나다 순(감마 → 베타 → 알파)으로 정렬되어 있다. 따라서 색인을 위에서 아래로 읽으면 용어가 가나다 순으로 나타나며, 계약 Y가 정한 정렬 순서(감마 → 베타 → 알파)와 일치한다.

## 3. 색인 참조

계약 Y가 정한 가나다 순 정렬(감마 → 베타 → 알파)에 따라 각 용어의 색인 참조 줄은 다음과 같다.

- 감마 — 색인 1번째 항목 (가나다 순 첫째 자리).
- 베타 — 색인 2번째 항목 (가나다 순 둘째 자리).
- 알파 — 색인 3번째 항목 (가나다 순 셋째 자리).
