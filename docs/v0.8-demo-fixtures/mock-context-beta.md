# 모사 프로젝트 컨텍스트 B (beta) — F-S1 재사용 시연용 (부분 재현 2/2)

이 파일은 v0.8 Skills 확장 시연(EX-DS)의 **재사용 시연(INV-5)** 보조 픽스처다. 실계약 문서가 아니다(검증 대상 계약 아님). 결함은 없다. `docs/v0.8-demo-fixtures/` 격리 경계 안에만 존재한다.

목적: 컨텍스트 A(alpha)와 **동일한 F-S1**을 **다른** 모사 프로젝트에 재등록만으로 재사용하고, 프로젝트 특정 값이 **Config/`io.input`으로만 상이하게 주입**됨을 보인다(INV-5). **F-S1의 `body`는 A와 완전히 동일(불변)**이며, A와의 유일한 차이는 아래 주입 값이다 — 이것이 재사용성의 기반이다.

## 재사용 대상 (불변 — A와 동일)

- Skill: `commit-message-writer` (F-S1, `.claude/skills/commit-message-writer/SKILL.md`).
- **`body` 불변.** A와 동일한 `body`를 그대로 참조한다 — 복제·수정 0.
- **`io` 계약 불변.** `input`=변경 요약, `output`=커밋 메시지 초안.

## 프로젝트 B 특정 값 (주입만 — body 하드코딩 0)

A와 대비되는 상이한 주입 값. 어느 값도 F-S1 `body`에 있지 않다.

| 프로젝트 특정 값 | 주입 채널 | 프로젝트 B 값 (A와 상이) |
|---|---|---|
| 커밋 컨벤션 스타일 | Config (Module scope, `target`=commit-message-writer) | 타입 접두어 없는 서술형 제목 |
| 허용 타입 목록 | Config | (미사용 — 타입 접두어 없음) |
| 스코프 규칙 | Config | 스코프 미부착 |
| 이슈 접두어 | Config | 본문 말미 `Refs: #<번호>` |
| 본문 언어 | Config | 한국어 |
| 제목 최대 길이 | Config | 72자 |

## 주입 예 (io.input)

- `변경 요약` = "결제 실패 시 재시도 로직 수정" (호출 Agent 제공 입력).

## 기대 결과 (관측 대조는 ex-ds-skills-observation.md)

- F-S1 `body`의 **동일한** 5단계 절차가 실행되고, 위 주입 값에 따라 프로젝트 B 스타일(타입 접두어 없음·한국어·`Refs:` 말미)의 초안이 산출된다.
- **A vs B 대조:** `body`·`io` 계약은 **완전히 동일(불변)**. 산출 초안이 다른 이유는 **오직 주입 값의 차이**다 — 본문 하드코딩이 아니다(INV-5).
- 재현 범위: **부분 재현**(모사 컨텍스트 2종). 실제 타 저장소 실등록·실행이 아니라 모사 컨텍스트 대조이며, 본문 하드코딩 0의 정적 대조는 CP2 소관임을 정직 명시한다(OQ-5, §2.3).
