# entry — 진입 / Entry Resolution Layer

상태: v1.2.1 스텁 (구조 이동 산출물 — 완전 저술은 후속 트랙)
상위: Universal Agentic Framework (root README/ARCHITECTURE 참조)

## 역할
entry는 UAF 파이프라인의 진입 지점을 해석하는 Layer다(Entry Resolution). `/new`·`/continue` 등 진입 명령을 받아 프로젝트가 어느 경로(Greenfield/Brownfield 등)로 진행할지 결정하고 다음 단계(Discovery)로 넘긴다.

정본: `entry/specs/01-entry.md` (v1.2.1 Phase 2에서 이 Layer로 이행 완료).
