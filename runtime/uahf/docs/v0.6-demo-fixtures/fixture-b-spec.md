# [시연 픽스처 — 실계약 문서 아님] fixture-b-spec — 시연 ⓑ 재작업 루프 대상 명세

> **시연 픽스처 — 실계약 문서 아님.** 이 파일은 v0.6 Loop Engine 시연(Task L10, 시연 ⓑ 재작업 루프)을 위해 구성된 **자기완결 대상 명세**다. specs/·framework/ 등 실계약 문서가 **아니다**. 이 파일과 그 산출물(output-b.md)은 `docs/v0.6-demo-fixtures/` **내부에만** 존재한다 (v0.6-demo-procedure §4.2 격리, CP2 전수 스캔 제외 verifier_scope).
>
> **의도적 결함 정당 보유 (시연 ⓑ용 — §A 작성 지시와 §B done의 의도된 불일치).** §A 작성 지시는 항목 **1~4번만** 정리하라 하지만 §B done ②는 **5개 항목 전건**을 요구한다. **결함 구조:** §A를 충실히 따른 **1차 산출은 done ②를 미충족**한다(산출물 결함) → CP2 Fail → 재작업 지시(expected_state = 5개 항목 전건 포함)로 **2차 산출이 충족 가능**(재판정 Pass). 근본 원인은 산출물 결함이므로 되돌림 대상은 Execute다(03 §3.1-B). 이 불일치는 재작업 루프(03 §8 예2) 실증을 위한 **의도적·정당 보유**이며 실계약 결함이 아니다.
