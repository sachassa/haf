  - **실측 범위 명시(06 §3.1 V4·L-20 준수)**: 위 "무변경"은 **사전 스냅샷 대비 MD5 바이트 수준 대조**(store 75파일 개별 해시 + 결합 해시 + index 프리픽스 해시)에 근거한다 — 세션 착수 시점 스냅샷을 기준선으로 한 바이트 불변이며, 좁은 대리 지표(카운트만) 하나로 결론하지 않았다. index는 append 대상이라 파일 mtime이 갱신되나 기존 라인 바이트는 프리픽스 해시로 불변 증명했다.
