## §0. 이 문서의 위치와 경계

- 본 문서는 UAF v1.1 마일스톤의 **CP2 독립 검증 리포트**다. Worker 완료 보고를 판정 근거로 삼지 않고(06 V1·INV-1), 판정 대상 산출물 자체를 직접 실측하여 독립 판정한다(06 §3.1).
- 최종 판정은 항목별 판정 집합에서 06 §3.2-C 규칙으로 **결정적으로** 도출된다(06 INV-5). Verifier는 위반의 경중을 재량으로 감면하지 않으며, 조건부 항목을 스스로 통과 처리하지 않는다(06 §3.2-C, 02 §3.2-A). 최종 승인(재량 판정)은 Advisor 소관이다(CP3).
- 본 문서는 어떤 정본도 재정의하지 않으며 새 용어를 신설하지 않는다. 판정 대상 산출물은 **일절 수정하지 않는다**(검증만).
