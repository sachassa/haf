## §0. 이 문서의 위치와 판정 경계

- **이 문서는 검증 리포트(06 §3.2-A) 1건이다.** Verify 연산(06 §3.1)의 출력이며, 판정 대상 산출물·물리 데이터(loop-data·memory-data·픽스처·dogfooding 설치본·scaffold-template·라이브 표면 포함)를 일절 수정·생성하지 않았다(06 INV-6 — 본 검증에서 생성한 저장소 파일은 이 리포트 1개뿐이다).
- **독립성(V1/INV-1).** 모든 판정은 산출물 자체와 파일 시스템 실측·독립 재계산(CLI 직접 실행·직접 json 파싱·전수 스캔·md5 재계산·cmp·행 재계수·디렉터리 재열거·status 라인 grep·정본 셀 대조·mtime 타임라인)을 근거로 했다. 각 Task 완료 보고, 각 산출물 자기 선언("전수 스캔 0건"·"실측 일치"·"무변경"·"재정의 0"·"7 line"·"Valid(Minimal)"), 사이클 내 CP2 리포트(verify-uahf-lessons.md·generic 검증 리포트)의 판정 기재, Advisor 게이트 C 예비 판정은 전부 **검사 대상(claim)으로만** 취급했고 판정 근거로 삼지 않았다.
- **② CLI 실행·④ 경계 스캔의 직접 수행(위임 done #1·#4).** 완료 조건 ②의 CLI 완료 기준 재관측은 위임·보고 문면 인용이 아니라 Verifier가 직접 `uahf-lessons`를 실행해 실측했다(item 6·7). 완료 조건 ④의 경계 전수 스캔도 Verifier가 직접 grep 전수 스캔으로 수행했다(item 12·13).
- **최종 승인 아님.** 본 리포트는 CP2 독립 판정이다. 최종 승인·재량 판정(CP3)과 사용자 승인은 Advisor·사용자 소관이며, 본 리포트는 조건부·재량 항목을 스스로 통과 처리하지 않는다(06 §3.2-C, 02 §3.2-A). 각 Adapter Conformance 문서·시연 기록이 verdict를 **스스로 최종 승인 처리하지 않고**(선취 금지) CP2/CP3로 이연한 것을 확인했다(item 2·4·21).
- **판정의 결정성(06 INV-5).** 최종 판정은 §3 항목별 판정 집합에서 06 §3.2-C 규칙으로 결정적으로 도출했다(§4).
- **VCS 부재의 판정 한계(V4 — §5 명시).** 저장소가 버전 관리되지 않아 시계열 byte-level diff는 불가하다. "무변경" 판정은 mtime 타임라인·write-set·status 라인·counts·md5 표본으로 corroboration하며, 그 제한을 verifier_scope(§5)에 정직히 명시한다(v0.4~v0.9 리포트 §5 동형). 픽스처 경계·Adapter 경계·docs/·설치본 응용 코드부는 정당 보유 격리 지점으로 C-3/AI 전수 스캔에서 제외하되, 그 근거·범위를 §5에 명시한다.
- **v1.0 작성 창(window) 확정(실측).** v1.0 산출물 전건 mtime은 2026-07-06 23:09:56 (install-manifest.template.md) ~ 2026-07-07 00:02:30 (adapter-compatibility-report.md) 구간이다. 이 구간이 "v1.0 창"의 실측 경계이며, 무변경 대상의 "v1.0 창 내 무수정" 판정은 이 경계 기준이다(§3.6).
