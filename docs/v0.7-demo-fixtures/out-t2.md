# 용어 색인 표 (계약 X 소비 → 계약 Y 실현 A)

용어는 계약 X(out-t1.md) 등장 순서(베타 → 알파 → 감마)로 나열한다. 각 정의 요약은 계약 X의 해당 용어 헤더 아래 `- 정의:` 줄 요지에 대응한다.

| 용어 | 정의 요약 |
|---|---|
| 베타 | 계약 X `## 용어: 베타` 헤더 아래 `- 정의:` 줄이 규정하는 베타 정의의 요지 |
| 알파 | 계약 X `## 용어: 알파` 헤더 아래 `- 정의:` 줄이 규정하는 알파 정의의 요지 |
| 감마 | 계약 X `## 용어: 감마` 헤더 아래 `- 정의:` 줄이 규정하는 감마 정의의 요지 |
