## §0. 이 문서의 위치와 판정 경계

- **이 문서는 검증 리포트(06 §3.2-A) 1건이다.** Verify 연산(06 §3.1)의 출력이며, verifier-protocol.md §2의 5단계(입력 수령 → 기준 확인 → 항목별 판정 → 최종 판정 도출 → 리포트 산출)를 그대로 밟았다. 판정 대상 산출물·물리 데이터(loop-data/·memory-data/·픽스처·라이브 표면 포함)를 일절 수정·생성하지 않았다 (06 INV-6 — 본 검증에서 생성한 저장소 파일은 이 리포트 1개뿐이다).
- **자기 적용 (위임 명시).** 스키마 = verification-report.md §2/§3/§4(6필드 절 구조 §0~§6·항목별 판정 5필드 표·결정적 도출), 유형 = criteria-catalog.md VT-1~VT-5, rework 포맷 = rework-instruction.md. 정본은 06 §3.2가 유지한다. 문서 구조는 docs/v0.7-verification-report.md 관례 동형이다.
- **독립성 (V1/INV-1).** 모든 판정은 산출물 자체와 파일 시스템 실측·독립 재계산(직접 파싱·재도출·전수 스캔·mtime/크기/md5 실측·행 재계수·디렉터리 재열거)을 근거로 했다. 전 Task(EX-H1 r2·EX-S1·EX-P1·EX-P2·EX-R1·EX-R2·EX-R3·EX-C1·EX-D1·EX-DH·EX-DS·EX-DP·EX-D2) 완료 보고의 self_check, 각 문서의 "자가 전수 스캔 0건"·"전건 일치"·"무변경" 기술, 시연 CP2 리포트 3건(verify-h/s/p)의 판정 기재는 전부 검사 대상(claim)으로만 취급했고 판정 근거로 삼지 않았다.
- **최종 승인 아님.** 본 리포트는 CP2 독립 판정이다. 최종 승인·재량 판정(CP3)은 Advisor 소관이며, 본 리포트는 조건부·재량 항목을 스스로 통과 처리하지 않는다 (06 §3.2-C, 02 §3.2-A).
- **판정의 결정성 (06 INV-5).** 최종 판정은 §3 항목별 판정 집합에서 06 §3.2-C 규칙으로 결정적으로 도출했다(§4). 위반의 경중을 재량으로 감면하지 않았다.
- **마일스톤 CP2 소관의 직접 수행.** 시연 수행 기록(demo.md §7)은 AI 비의존 3건·카탈로그 도출 1건·spec 일치 1건을 "판정 유보 — 마일스톤 CP2 소관"으로 정직하게 이월했다(충족 위장·조건부 자기 통과 0 — 정확한 라우팅). 본 리포트가 그 배정분을 직접 수행한다 — specs/08·09·10 §3 정적 스캔·카탈로그 도출 대조·규격 셀 단위 일치를 Verifier가 직접 실측해 판정한다(items #6~#13, verifier_scope §5). demo.md가 남긴 "판정 유보 CP3"(Advisor 최종 승인)는 CP2 대상이 아니며 다음 게이트로 남긴다.
- **잔존 서술 판정 규칙 (rework-instruction §4 적용).** "무변경"·"잔여 0" 류 전칭 판정은 라이브 본문에 적용했고, 이력 행(§9)·시점 명시 실측 스냅샷(예: 각 binding·demo-procedure의 시점-스코프 "미생성" 기록)은 계상하지 않았다(§3.7).
- **Advisor 제공 사실의 판정 기준.** ⑫의 planner.md 변경 = 사용자 지시 Task EX-R3(Worker 위임)·verifier.md 변경 = EX-R3(권한 차단으로 Advisor 직접 수정)의 **선언된 승인 개정**으로 분류한다(위임 명시) — "본체 무변경" 판정에서 무단 변경으로 계상하지 않는다. DP-E1~E8·OQ 해소 결정의 판정 기준은 결정의 재평가가 아니라 **결정 기록의 실재와 정본 정합(계약 재정의 여부)**이다.
