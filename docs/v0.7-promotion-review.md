## §2. 판정

### §2.1 L-13 — Active 승격 승인 (Advisor, 2026-07-06)

- **stable_id**: L-13. **요지**: 기존 Baseline 문서의 개정 위임에는 상태 라인·이력 행 라벨의 기대 문면을 done 또는 constraints에 명시하라 — 관례 의존 지시는 수임자마다 갈린다.
- **승격 근거**: 동일 결락이 한 Wave에서 3회 반복(위반 아닌 관례 편차이나 재개정 비용 실발생 — r2×3·r3×1) + 같은 세션 내 예방 실증(WF8 선반영 → 재개정 0회). 재발 방지 가치·적용 조건이 명확하다.
- **승인 참조 content 자기완결**: mi-0047 content에 `approval_ref` = 본 문서 §2.1 첨부 (lessons.md §3.2 관례).

### §2.2 재발 판정 (Judge Recurrence — 05 §3.1-C)

- **failure_signature**: 개정 위임 done이 상태 라인·이력 행 라벨 처리를 명시하지 않아 수임자 처리 편차 발생 (v0.7 WF13~WF15).
- **matched_lesson_id**: **L-08** (위임 done 문구 정밀도). **was_recalled**: true — 세션 진입 Consult 회수 집합(Active Lesson 12건 L-01~L-12, 계획 파일 §2 기록)에 포함. 회수 이력 출처: 세션 회수 기록(세션 자체는 루프 상태 기록으로 구동되지 않아 수동 제공 — handoff v0.6 §3.4 단서).
- **verdict**: **Recurrence** — done이 검증 가능했으나 표기 관례 항목을 누락한 것은 done 정밀도 결락의 재발 국면.
- **follow_up**: L-13 등록·승격 — L-08을 "개정 위임의 관례 기대 문면 명시" 국면으로 확장하는 강화 Lesson (supersede 아님, L-08 Active 유지). 게이트 A 운용에 "개정 위임 시 상태 라인·라벨 기대 문면 명시"를 관행 추가.
