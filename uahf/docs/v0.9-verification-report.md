## §0. 이 문서의 위치와 판정 경계

- **이 문서는 검증 리포트(06 §3.2-A) 1건이다.** Verify 연산(06 §3.1)의 출력이며, verifier-protocol.md §2의 5단계(입력 수령 → 기준 확인 → 항목별 판정 → 최종 판정 도출 → 리포트 산출)를 그대로 밟았다. 판정 대상 산출물·물리 데이터(loop-data/·memory-data/·픽스처·scaffold-template/·라이브 표면 포함)를 일절 수정·생성하지 않았다 (06 INV-6 — 본 검증에서 생성한 저장소 파일은 이 리포트 1개뿐이다).
- **독립성 (V1/INV-1).** 모든 판정은 산출물 자체와 파일 시스템 실측·독립 재계산(직접 파싱·전수 스캔·md5 재해시·행 재계수·디렉터리 재열거·status 라인 grep·정본 셀 대조)을 근거로 했다. 각 Worker 완료 보고, 각 산출물의 자기 선언("전수 스캔 0건"·"실측 일치"·"무변경"·"재정의 0"·"7 line"·"15종"), 시연 CP2 리포트(verify-scaffold.md)의 판정 기재, Advisor 게이트 C 예비 판정은 전부 **검사 대상(claim)으로만** 취급했고 판정 근거로 삼지 않았다.
- **완료 조건 ② 경계 스캔·시연 재관측의 직접 수행(위임 done #2).** ROADMAP v0.9 완료 조건 ②(Core Claude 의존 0건)의 경계 전수 스캔과 완료 조건 ③(설치·루프 시연)의 실물 재관측은 위임·보고 문면 인용이 아니라 Verifier가 직접 실측했다(item #3·#4, §3.3·§3.6). 시연 수행 기록(demo.md)이 "판정 유보 — 마일스톤 CP2 소관"으로 이월한 §3 AI 비의존 정적 스캔 1건도 본 리포트가 직접 전수 스캔으로 수행했다(item #3).
- **최종 승인 아님.** 본 리포트는 CP2 독립 판정이다. 최종 승인·재량 판정(CP3)과 사용자 승인은 Advisor·사용자 소관이며, 본 리포트는 조건부·재량 항목을 스스로 통과 처리하지 않는다 (06 §3.2-C, 02 §3.2-A).
- **판정의 결정성 (06 INV-5).** 최종 판정은 §3 항목별 판정 집합에서 06 §3.2-C 규칙으로 결정적으로 도출했다(§4).
- **VCS 부재의 판정 한계 (V4 — §5 명시).** 저장소가 버전 관리되지 않아 byte-level diff는 불가하다. "무변경" 판정은 mtime 타임라인·write-set·counts·md5 표본으로 corroboration하며, 그 제한을 verifier_scope(§5)에 정직히 명시한다(v0.4~v0.8 리포트 §5 동형). 픽스처 경계(docs/v0.5~v0.9-demo-fixtures/)는 의도적 결함·환경 토큰 정당 보유 격리 지점으로 C-3/AI 전수 스캔에서 제외하되, v0.9 설치본 Core부(new-project/framework/core·runtime)의 CK-6 재스캔은 수행했다.
