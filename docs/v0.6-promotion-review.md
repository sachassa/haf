## §2. 승인 (Candidate → Active, 2건)

### L-12 — 위임문의 구조 전제 실측 대조

- **failure**: L3(편입 ②) 위임 done 3이 대상 문서(verification-checklist.md)에 "이력 절 append"를 요구했으나, 실측 결과 그 문서에는 이력 절이 실재하지 않았다 — 위임문 전제와 대상 실상의 불일치로 Worker가 착수 후 검출·에스컬레이션(OQ-1), r2 재개정 라우팅 1회 발생.
- **cause**: 위임 done이 대상 산출물의 기존 구조(절·이력 절 존재)를 실측 없이 전제했다 — L-07(상태 서술은 실측 후 기록)의 위임문 작성 국면 재발.
- **lesson**: 위임 done이 대상 산출물의 기존 구조·요소의 실재를 전제할 때, 발신 전 그 전제를 파일 시스템 실측으로 대조하라 — 위임문의 존재 전제도 실측 대상이다 (L-07의 위임 발신 국면 확장, L-11의 자매 — 위임문 자체가 검증 대상).
- **승격 3조건**: ①5필드 전건 충족 ②실재 근거 = L3 r1 완료 보고(Worker의 실측 검출 — grep 0건 + 전 헤딩 열거)와 r2 재개정 기록(verification-checklist.md §9) ③Advisor 승인(본 심사). → **승인**.

### BP-03 — Frozen 미명세 지점의 정본 문면 인스턴스 해소

- **success**: v0.6에서 Frozen 03의 미명세 지점 3건 — ⑴ `ref` 괄호 열거의 한정성(DP-L5) ⑵ 에스컬레이션 종료 전이의 `to_stage`(L9 OQ-1) ⑶ 한도 초과 시점의 `retry_count` 표기(L9 OQ-2) — 를 **정본 자신의 문면이 지정하는 값·목적지·조건의 인스턴스**로 해소하고(§3.1-A 실패 경로 전이 목적지 "에스컬레이션", §3.1-B 초과 조건이 기록 필드로 참, 04/05 §9 결정 기록의 소관 배정), 산출물 결정 기록 절에 § 포인터와 함께 명문화했다. CP2가 3건 전부 재정의 0·정합으로 확인(v0.6-verification-report #16 등) — Frozen 개정 0회로 통합 마일스톤 완주.
- **practice**: Frozen 정본의 미명세 지점을 만나면 새 값·해석을 창설하지 말고, 정본 자신의 문면(전이 목적지·조건식·타 spec 결정 기록)이 지정하는 값을 인스턴스로 채택하고 결정 기록 절에 § 포인터와 함께 명문화하라. 한정 해석 시 Frozen 개정이 필요해지는 지점은 비한정 해석의 정본 내 근거(교차 결정 기록의 정합)를 먼저 찾는다.
- **승격 3조건**: ①필드 전건 충족 ②실재 근거 = CP2 Pass(v0.6-verification-report — 결정 기록 3건 전부 03 정본 인스턴스로 확인) ③Advisor 승인(본 심사). → **승인**.

## §4. 재발 판정 (Judge Recurrence, 1건 — mi-0036)

- **failure_signature**: 위임문의 존재 전제(대상 문서의 이력 절)가 실측 없이 기입되어 대상 실상과 불일치 (L3 r1).
- **matched_lesson_id**: **L-07** (상태 서술은 실측 후 기록 — 존재 주장 실측).
- **was_recalled**: **true** — v0.6 세션 착수 Consult 회수 집합(계획 파일 기록: L-01~L-11·BP-01·BP-02)에 L-07 포함. *회수 이력 입력은 이번 세션까지 수동 제공(세션 자체는 루프 상태 기록으로 구동되지 않음 — 03 관례는 시연에서 확립). 차기 세션부터 Consult 전이 이벤트 `ref`(DP-L5)에서 도출 가능.*
- **verdict**: **Recurrence** — L-07이 회수되었음에도 위임문 작성 국면에서 같은 부류의 실수(존재 전제 미실측)가 발생했다 (v0.4 mi-0021의 L-06, v0.5 mi-0030의 L-07 재발에 이은 L-07 계열 재발).
- **follow_up**: L-12 등록·승격(§2) — L-07을 위임 발신 국면으로 확장하는 **강화 Lesson**(supersede 아님, L-07 유지). 게이트 A 점검 항목에 "done의 존재 전제 실측 대조"가 포함되도록 차기 세션 관행에 반영.

Record 절차(memory-binding §3.1)와 계약(04 §3.1-A)은 동일하며 등록 주체는 계약 사안이 아니다. 차기 세션 심사 시 관례 재정렬 여부 판단.
