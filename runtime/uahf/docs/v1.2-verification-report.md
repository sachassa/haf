## §0. 이 문서의 위치와 경계

- 본 문서는 UAF v1.2 마일스톤의 **CP2 독립 검증 리포트**다. Worker 완료 보고·Advisor 게이트 기록을 판정 근거로 삼지 않고(06 V1·INV-1), 판정 대상 산출물 자체를 직접 실측하여 독립 판정한다(06 §3.1). 완료 보고·게이트 기록은 검사 대상(claim)일 뿐이다.
- 최종 판정은 항목별 판정 집합에서 06 §3.2-C 규칙으로 **결정적으로** 도출된다(06 INV-5). Verifier는 위반의 경중을 재량으로 감면하지 않으며, 조건부 항목을 스스로 통과 처리하지 않는다(06 §3.2-C, 02 §3.2-A). 최종 승인(재량 판정)은 Advisor 소관이다(CP3).
- 본 문서는 어떤 정본도 재정의하지 않으며 새 용어를 신설하지 않는다. 판정 대상 산출물은 **일절 수정하지 않는다**(검증 전용, 06 INV-6·V5).

### 제외하거나 검사하지 못한 범위(정직 명시 — 06 V4)

- **byte-level diff 불가.** 저장소가 git 관리 하가 아니어서(`.git` 부재 실측) UAHF·uaf/ 정본의 내용 byte diff는 수행 불가. 무수정 판정은 mtime 창 전수 스캔 + 문서 상태 라인/이력 + 콘텐츠 성격의 삼중 실측으로 대체했다. 이 방식은 "v1.2 착수 창(2026-07-07 07:00) 이후 수정된 UAHF 정본 파일 = 명시 개정 3건뿐, uaf/ 정본·루트 ARCHITECTURE·specs/·운영 데이터 0건"을 강한 근거로 확립하나, 이론적으로 mtime 보존 편집(touch 없는 in-place)은 탐지 밖이다 — 다만 그런 편집 흔적(상태 라인·이력에 v1.2 항목)도 0건이다.
- **§ 포인터 전건 대조 미실시.** 세 바인딩·두 명령이 인용하는 개별 § 포인터(다수)의 대상 절 헤더 1:1 전건 대조는 수행하지 않았다 — load-bearing 인용(§4 바인딩 지점 매핑·T-C r2 교정·표기 차이·데이터↔바인딩 참조·순환)은 표본 대조했고 불일치 0. 잔여 § 포인터의 개별 정확성은 표본 신뢰 수준이며 전수 확정은 아니다.
- **Discovery 실행 메타 산식·Metrics.** 두 events.jsonl의 Confidence 값 자체의 산정 타당성(예: intent 0.85가 근거에 정확히 상응하는가)은 정본이 산식을 구현 버전으로 이연(02 §3.16·§3.12 근거 등급)했으므로 판정 대상이 아니다. 본 판정은 값의 **정본 규칙 정합**(임계 대비 포화 판정·근거 등급 표기·전이 유발)까지만 검사했다.
- **런타임 실행 행위.** Advisor Consult 정독·Scaffold 배치의 런타임 수행 행위 자체는 산출물 로그 대상이 아니며, Contract의 선택 입력 배치(두 소비 지점)로 표면 실현을 확인했다.
